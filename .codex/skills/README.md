# Skills

Human-readable notes about promoted orchestrator workflows may live here after
they have appeared in three separate cases or tasks.

Codex-discoverable repo skills live under `.agents/skills/<name>/SKILL.md`.
Use that path when a workflow should be invokable by Codex through the skills
harness.

Do not prebuild skills speculatively. Start with candidate-workflow memories,
promote only after repeated use, and keep each skill contract explicit enough
for Codex or a subagent to apply without relying on hidden conversation context.
