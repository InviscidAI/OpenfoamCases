# Re 3900 Circular Cylinder LES

Paper-matched OpenFOAM v2606 setup for Parnaudeau et al.,
Physics of Fluids 20, 085101 (2008).

- `D = 1`, `Uinf = 1`, `nu = 1/3900`
- Domain: `20D x 20D x piD`
- Mesh: pure-hex O-grid generated by `scripts/generate_ogrid_mesh.py`.
  The default `benchmark-5m` preset keeps the paper domain and spanwise count
  while staying near the preferred mesh budget:
  `576 x 176 x 48 = 4.87M` cells. It uses a flatter radial distribution than
  the startup mesh to improve wake resolution. The old smaller startup setup is
  available as `--preset startup`.
- Solver: `pimpleFoam`
- LES model: `WALE` for the overnight stability run. `dynamicKEqn` was the
  first-choice SGS model, but it proved unstable during full-mesh startup.
- Velocity convection: `bounded Gauss linear`
- Time integration: `CrankNicolson 0.9` for startup damping; pure
  `CrankNicolson 1.0` produced strong odd-even startup force oscillations.
- Startup: inlet ramp from rest to `Uinf = 1` over `5 D/U` to avoid an
  impulsive no-slip initialization.
- Time step: fixed `deltaT = 0.003 D/U`, matching the Parnaudeau HR LES.
  The earlier adaptive CFL-1 proof run was stable, but the fixed paper time
  step is the benchmark setting.
- Statistics window: `timeStart = 150`, `endTime = 400`, matching the
  Parnaudeau HR LES statistics duration of `250 D/U` after transient removal.
- HPC migration guards live in `HPC_MIGRATION_GUARDS.md`. On the target
  machine, have Codex retune decomposition and output frequency before the
  production run; these settings are machine- and filesystem-dependent.
- Pressure solver: `GAMG` with `DIC` smoothing. A controlled one-step serial
  and 24-rank parallel test ruled out pressure pinning as the earlier GAMG
  crash cause.

Primary validation targets:

- `St ~= 0.208`
- recirculation length `Lr/D ~= 1.5-1.6`
- mean and second-order wake statistics after `t = 150 D/U`

Monitor a run once:

```sh
scripts/monitor_run.sh
```

Or poll every five minutes:

```sh
scripts/monitor_run.sh 300
```

Monitor a named log:

```sh
scripts/monitor_run.sh 300 run.status log.tune_cn09_gamg_ramp5
```

HPC launch pattern:

```sh
NP="${SLURM_NTASKS:-24}" GENERATE_MESH=1 LOG=log.pimpleFoam scripts/run_hpc.sh
```
