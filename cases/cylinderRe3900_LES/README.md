# Re 3900 Circular Cylinder LES

Paper-matched OpenFOAM v2606 setup for Parnaudeau et al.,
Physics of Fluids 20, 085101 (2008).

- `D = 1`, `Uinf = 1`, `nu = 1/3900`
- Domain: `20D x 20D x piD`
- Mesh: pure-hex O-grid generated by `scripts/generate_ogrid_mesh.py`
  (`512 x 128 x 64 = 4.19M` cells by default)
- Solver: `pimpleFoam`
- LES model: `WALE` for the overnight stability run. `dynamicKEqn` was the
  first-choice SGS model, but it proved unstable during full-mesh startup.
- Velocity convection: `bounded Gauss linear`
- Time integration: `CrankNicolson 0.9` for startup damping; pure
  `CrankNicolson 1.0` produced strong odd-even startup force oscillations.
- Startup: inlet ramp from rest to `Uinf = 1` over `5 D/U` to avoid an
  impulsive no-slip initialization.
- Startup timestep cap: `maxDeltaT = 0.001`, `maxCo = 0.15` until the ramped
  configuration proves stable.
- Pressure solver: `GAMG` with `DIC` smoothing. A controlled one-step serial
  and 24-rank parallel test ruled out pressure pinning as the earlier GAMG
  crash cause.

Primary validation targets:

- `St ~= 0.208`
- recirculation length `Lr/D ~= 1.5-1.6`
- mean and second-order wake statistics after `t = 150 D/U`

Monitor a run once:

```sh
scripts/monitor_run.sh
```

Or poll every five minutes:

```sh
scripts/monitor_run.sh 300
```
